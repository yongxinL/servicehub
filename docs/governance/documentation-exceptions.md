# Documentation Exceptions

Records temporary and standing exceptions to Nexora Governance for this project. One-time feature or release deviations normally remain with the affected artifact (specification or release record) rather than here.

Exceptions cannot waive the non-exception controls: source-of-truth integrity, secret handling, human approval authority, durable repository memory, no silent specification change, and no invented decisions or approvals.

```markdown
| Field | Value |
|---|---|
| Type | Temporary / Standing |
| Rule affected | Central chapter and section |
| Reason | |
| Impact | |

| Approved by / mode / date | project-owner / owner-self-approval / YYYY-MM-DD |
| Review trigger | |
| Resolution condition | Required for temporary exceptions |
| Status | Active / Resolved / Withdrawn |
```
