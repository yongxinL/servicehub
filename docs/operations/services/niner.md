# 9Router (niner) — Experimental AI Gateway

**Service:** `routeniner` (Compose: `compose/route.yml`)  
**Image:** `decolua/9router:latest` (reviewed version v0.5.112 at ADR-011 Stage 4; pinning intentionally omitted per owner decision)  
**Hostname:** `cerberus.${DOMAIN_NAME}` (Traefik HTTPS)  
**Internal Port:** 20128  
**Status:** Experimental (ADR-011)

---

## Overview

9Router is deployed as an experimental unified AI gateway for Claude Code, OpenAI Codex CLI, and OpenCode. It routes requests to approved free providers (NVIDIA AI/NIM, OpenCode Free) with a free-only fallback policy and no paid-provider fallback.

---

## Architecture

| Layer | Configuration |
|-------|---------------|
| **Hostname** | `cerberus.${DOMAIN_NAME}` (derived from `CERBERUS_DOMAIN` or `DOMAIN_NAME`) |
| **Traefik Routers** | Generated by `scripts/gen-admin-rules.py` |
| **API Router** | `Host(cerberus.${DOMAIN_NAME}) && PathPrefix(/v1)` — priority 200 — `secure-chain` only — Bearer API key enforced by `REQUIRE_API_KEY=true` |
| **Dashboard Router** | `Host(cerberus.${DOMAIN_NAME})` — priority 100 — `secure-chain` + `TRUSTED_IP` + basic auth |
| **Persistence** | `${APPS_DATA}/route/niner/` → `/app/data` (bind mount) |
| **Data Dir** | `DATA_DIR=/app/data` (SQLite at `/app/data/db/data.sqlite`) |

## Provider Configuration (Manual Dashboard)

### Prerequisites
1. Run `scripts/setup.sh` to generate `ROUTE_NINER_INITIAL_PASSWORD` in `.env`
2. Deploy: `docker compose up -d routeniner`
3. Access dashboard: `https://cerberus.${DOMAIN_NAME}/dashboard` (from `TRUSTED_IP` only)

### Step-by-Step

1. **Log in** using the generated `ROUTE_NINER_INITIAL_PASSWORD`
2. **Change password** via 9Router Settings → Change Password (UI only)
3. **Connect NVIDIA:**
   - Providers → Add API Key → Provider: `nvidia`
   - Enter NVIDIA API key (from NVIDIA AI/NIM console)
   - Select desired models
4. **Connect OpenCode Free:**
   - Providers → Connect OpenCode Free
   - No API key required; models auto-fetched
5. **Set routing priority:**
   - NVIDIA as preferred route
   - OpenCode Free as fallback
6. **Disable paid/subscription routes** — ensure no paid providers are connected
7. **Enable built-in RTK** — Settings → Token Saver (RTK)
8. **Generate client API keys:**
   - Settings → API Keys → Create
   - Create separate keys for: `claude-code`, `codex-cli`, `opencode`
   - Save keys securely (not in Git)
9. **Record provider/model choices** (no credentials in docs)

## Client Configuration

### Gateway URL
```
https://cerberus.${DOMAIN_NAME}/v1
```

### Authentication
Each client uses a separate Bearer API key generated in step 8 above.

### Claude Code
```bash
# ~/.claude/config.json or equivalent
{
  "api_base": "https://cerberus.${DOMAIN_NAME}/v1",
  "api_key": "<CLAUDE_CODE_API_KEY>"
}
```

### Codex CLI
```bash
# ~/.codex/config.toml or env
OPENAI_API_BASE="https://cerberus.${DOMAIN_NAME}/v1"
OPENAI_API_KEY="<CODEX_API_KEY>"
```

### OpenCode
```bash
# ~/.config/opencode/opencode.toml or equivalent
[api]
base_url = "https://cerberus.${DOMAIN_NAME}/v1"
api_key = "<OPENCODE_API_KEY>"
```

### Harmless Test
```bash
curl -H "Authorization: Bearer <API_KEY>" \
     -H "Content-Type: application/json" \
     -d '{"model":"nvidia/nemotron-3-ultra","messages":[{"role":"user","content":"Hello"}]}' \
     https://cerberus.${DOMAIN_NAME}/v1/chat/completions
```

### Rollback to Native Provider
Remove gateway config or set client's `api_base` back to native endpoint.

## NVIDIA Rate Controls

| Type | Mechanism |
|------|-----------|
| **Technically enforced** | Single-model combos; no fusion/parallel routing; RTK enabled; paid routes absent |
| **Operational** | One long coding-agent session at a time (team policy) |
| **Observed only** | 429 frequency, `Retry-After`, fallback events, RPM via Alloy metrics |

**No proactive 36/40 RPM enforcement.** Gate 14 (ADR-011) remains open pending runtime evidence.

## Backup and Restore

See [9ROUTER-BACKUP-RESTORE.md](../runbooks/9ROUTER-BACKUP-RESTORE.md).

### Persistent State
| Path | Content |
|------|---------|
| `${APPS_DATA}/route/niner/db/data.sqlite` | Primary SQLite (providers, API keys, combos, usage) |
| `${APPS_DATA}/route/niner/db/backups/` | Automatic SQLite backups |
| `${APPS_DATA}/route/niner/data-home/jwt-secret` | Auto-generated JWT signing key |

**Backup tier:** Tier 2 (weekly, ADR-007). Crash-consistent copy.

### Restore Procedure
1. Stop container: `docker compose stop routeniner`
2. Restore `${APPS_DATA}/route/niner/` from Tier 2 archive
3. Start: `docker compose up -d routeniner`
4. Verify dashboard login and API key validity

## Upgrade and Rollback

### Pre-Upgrade
1. Backup `${APPS_DATA}/route/niner/`
2. Review release notes for new upstream version
3. Optionally verify image digest from `docker pull decolua/9router:latest`

### Upgrade
```bash
# Update compose/route.yml image tag + digest
docker compose pull routeniner
docker compose up -d routeniner
```

### Rollback
```bash
# Revert compose/route.yml to previous digest
docker compose up -d routeniner
```

## Security

- No public native port (port 20128 not published on host)
- Dashboard restricted to `TRUSTED_IP` + JWT session
- `/v1` API protected by per-client Bearer keys (`REQUIRE_API_KEY=true`)
- HTTPS via Traefik (Let's Encrypt)
- `AUTH_COOKIE_SECURE=true`, `ENABLE_REQUEST_LOGS=false`
- No secrets in Compose, labels, or Git

---

## Observability

- Container health: `docker compose ps routeniner`
- CPU/memory: Alloy cAdvisor scrape
- Logs: Docker log driver → Alloy → VictoriaLogs
- Metrics: 9Router dashboard UI (provider health, quota, usage)
- Custom probes: External synthetic probe for `/v1` endpoint (Stage 6)

---

## Known Limitations (Experimental)

- OpenCode Free tested on v0.5.112 only
- No proactive NVIDIA rate limiting
- Cloud sync disabled (no `CLOUD_URL`)
- No formal health endpoint — dashboard accessibility is liveness-only
- Single container (no HA)
