## Specifications

Specifications, feature plans, and tasks are owned by GitHub Spec Kit under `specs/`, created at Spec Kit initialization. Their index is `specs/README.md` once created and verified compatible. If the installed Spec Kit version cannot tolerate that file, the specification index is maintained in this section instead, and the reason is recorded in [governance/documentation-exceptions.md](governance/documentation-exceptions.md).

## Rules of use

- Check [governance/source-of-truth-register.md](governance/source-of-truth-register.md) before creating a document.
- Create artifacts only when their trigger applies; empty areas are valid.
- Update the area index in the same commit as the artifact.
