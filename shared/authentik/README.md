# Authentik — ServiceHub

> Open-source Identity Provider (IdP) and SSO, used for forward-authentication across the stack.

## Overview

[Authentik](https://goauthentik.io/) provides single sign-on and forward-authentication for Traefik-protected services (for example Grafana). It can be extended to cover any service behind the reverse proxy.

Authentik is defined in [`compose/authn.yml`](../../compose/authn.yml) and built from [`shared/authentik/Dockerfile`](Dockerfile) (`FROM ghcr.io/goauthentik/server:${IMAGE_TAG}`).

## Components

The stack runs three containers:

| Service | Command | Role |
|---|---|---|
| `authnsvrinit` | `chown -R 1000:1000 /data /templates` | One-shot permission fixer; runs to completion before the worker starts |
| `authnworkers` | `worker` | Background processing — flows, policies, outpost sync, notifications |
| `authnservice` | `server` | Web server / UI, routed by Traefik at `https://${AUTHN_DOMAIN}` |

Startup order: `authnsvrinit` completes → `authnworkers` starts (after a healthy PostgreSQL) → `authnservice` starts (after a healthy Traefik and the worker).

## Service details

| Detail | Value |
|---|---|
| URL | `https://${AUTHN_DOMAIN}` |
| Initial setup | `https://${AUTHN_DOMAIN}/if/flow/initial-setup/` on first boot |
| Internal port | 9000 |
| Database | PostgreSQL (`${AUTHN_DBNAME}`) |
| Data persistence | `${APPS_DATA}/webapps/authentik/media` and `.../templates` |
| Image tag | `AUTHN_TAG` (e.g. `2026.8`) |
| Shared memory | `shm_size: 512mb` |
| Analytics / update checks | Disabled (`AUTHENTIK_DISABLE_STARTUP_ANALYTICS`, `AUTHENTIK_DISABLE_UPDATE_CHECK`) |

## Configuration

Set in `.env` (see [`env.example`](../../env.example)):

| Variable | Description |
|---|---|
| `AUTHN_DOMAIN` | Authentik hostname (e.g. `login.example.com`) |
| `AUTHN_TAG` | Authentik image tag (e.g. `2026.8`) |
| `AUTHN_DBNAME` | PostgreSQL database name (default `svchubauthtk`) |
| `AUTHN_PASSWD` | Auto-generated by `setup.sh`; database password |
| `AUTHN_SECRET` | Auto-generated by `setup.sh`; secret key for signing |
| `PGRSQL_HOST` / `PGRSQL_PORT` | PostgreSQL connection target (`dbsvcpgsqldb:5432`) |
| `SQLDB_USER` / `SQLDB_PASS` | Shared database credentials |
| `EMAIL_HOST` / `EMAIL_PORT` / `EMAIL_USER` / `EMAIL_PASS` / `EMAIL_FROM` | Outbound email for invitations and recovery |
| `TRUSTED_IP` | Trusted proxy CIDRs (`AUTHENTIK_LISTEN__TRUSTED_PROXY_CIDRS`) |

`AUTHN_DBNAME` must be listed in `PGRSQL_DBLIST` so the PostgreSQL init script creates it on first start.

## Data & persistence

| Container path | Host path | Purpose |
|---|---|---|
| `/data` | `${APPS_DATA}/webapps/authentik/media` | Uploaded media |
| `/templates` | `${APPS_DATA}/webapps/authentik/templates` | Email / flow templates |

`authnsvrinit` chowns both directories to UID/GID `1000` on every boot, so the directories can be created empty beforehand. `authnworkers` runs as `root` and mounts the Docker socket (it manages outpost containers).

## Setup (first boot)

1. Start the service:

    ```bash
    docker compose up -d authnservice
    ```

2. Open `https://${AUTHN_DOMAIN}/if/flow/initial-setup/` and create the admin account.
3. In the Authentik admin UI, create the objects you need (applications, providers, flows, groups).
4. To protect a service with **forward-auth**, create a Proxy Provider (forward auth) and an Application, then bind an Embedded Outpost. The Traefik middleware already points at the outpost endpoint:

    ```
    http://authnservice:9000/outpost.goauthentik.io/auth/traefik
    ```

    (defined in [`shared/traefik/advanced/middlewares-authentik.yml`](../traefik/advanced/middlewares-authentik.yml))

5. Attach `authentik-forwardauth@file` to the target router's middleware chain. For example, Grafana already does this in `compose/obsvc.yml`.

> **Reference:** forward-auth integration pattern — <https://github.com/brokenscripts/authentik_traefik>

## Operations

```bash
# Restart the server and worker
docker compose restart authnservice authnworkers

# Follow server logs
docker compose logs -f authnservice

# Follow worker logs
docker compose logs -f authnworkers
```

## Notes

- The Traefik dashboard uses **basic auth by default**; Authentik forward-auth is optional. When you switch the dashboard to forward-auth, remove `dashboard-whitelist` from its middleware chain.
- Database schema migrations run automatically when the server/worker starts.
- If you change `AUTHN_SECRET`, existing sessions and encrypted values are invalidated.
