## Authority

This project is governed by the Nexora Governance release identified above. The central manual at that tag is authoritative for governance rules; this file is a pointer and does not copy them.

## Upgrade rule

This project does not follow the central default branch. Upgrades are reviewed and adopted explicitly, and both this file and `docs/governance/governance-adoption.md` are updated in the same commit.

## Exceptions

Project exceptions are recorded in [docs/governance/documentation-exceptions.md](docs/governance/documentation-exceptions.md) and cannot waive the central non-exception controls.
